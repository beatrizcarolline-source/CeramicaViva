# CeramicaViva
Repositório de software de loja de cerâmica.

## Contexto
Sistema de gerenciamento do estabelecimento Cerâmica Viva, com o intuito de supervisionar o estoque de produtos, registrar informações de clientes, efetuar vendas e cadastrar pedidos.

- Cadastrar usuário
- Cadastrar produto
- Relatório mensal do que entrou e saiu do caixa
